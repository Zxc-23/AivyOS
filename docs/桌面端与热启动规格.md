## 一、桌面端架构 核心

### 1.1 技术选型

    AivyOS 桌面端采用 Tauri 2.0 作为应用壳层，Python 作为 AI 核心引擎。Tauri 提供原生窗口、系统托盘、全局热键等桌面能力，Python 通过子进程 + IPC 通信提供 AI 功能。

      | 维度 | Tauri 2.0 | Electron | 选型理由 |
| --- | --- | --- | --- |
| 安装包大小 | ~8 MB | ~150 MB | Tauri使用系统WebView，不打包Chromium |
| 内存占用 | ~80 MB | ~300 MB | 无Node.js运行时开销 |
| 启动速度 |
      架构决策 — Tauri 壳层负责 UI 渲染（React + WebView）、系统托盘、全局热键、自动更新、原生通知。Python 子进程负责 AI 推理（LLM/ASR/TTS）、记忆管理、工具执行。两者通过 Unix Domain Socket / Named Pipe 通信，延迟 &lt;1ms。

## 二、自动更新 新增

    AivyOS 能自动检测、下载和安装更新，全程无需用户干预。更新包采用增量发布——只下载变更部分，典型更新包 &lt;5MB。

| --- | --- |
| 检测频率 | 每6小时检查一次（可配置） |
| 检测方式 | GET /update/{target}/{arch}/{current_version} |
| 响应格式 | { version, pub_date, notes, update_type } |

import { check, DownloadAndInstall } from "@tauri-apps/plugin-updater";

async function checkAndUpdate() {
    const update = await check();

    if (!update) {
        console.log("已是最新版本");
        return;
    }

    console.log(`发现新版本: ${update.version}`);
    console.log(`更新内容: ${update.notes}`);

    // 根据更新类型决定行为
    switch (update.update_type) {
        case "critical":
            // 安全更新：立即下载安装
            await sendNotification({
                title: "AivyOS 安全更新",
                body: `正在更新到 v${update.version}...`
            });
            await update.downloadAndInstall();
            await applyHotUpdate();  // 热启动流程
            break;

        case "feature":
            // 功能更新：询问用户
            const accept = await showUpdateDialog(update);
            if (accept) {
                await update.downloadAndInstall();
                await applyHotUpdate();
            }
            break;

        case "patch":
            // 补丁更新：静默下载，下次启动时安装
            await update.download();
            // 标记为待安装，下次启动时应用
            break;
    }
}
```

## 三、热启动 核心

    热启动（Hot Restart）是 AivyOS 的核心工程能力——更新代码/模型后不中断服务，用户无感知地切换到新版本。即使必须重启，也通过状态快照实现秒级恢复。

### 3.1 热交换（Hot Swap）

    热交换是热启动的核心机制：在不停止进程的前提下，卸载旧模块、加载新模块、切换流量。

#### 3.1.1 Python 模块热交换

```
import importlib
import sys
from pathlib import Path

class HotSwapper:
    """Python模块热交换器"""

    def __init__(self, module_dir="./aivyos/modules"):
        self.module_dir = Path(module_dir)
        self.loaded_modules = {}  # name → module

    def hot_reload(self, module_name):
        """热重载单个模块"""
        if module_name in sys.modules:
            old_module = sys.modules[module_name]
            # 保留旧模块的全局状态（如数据库连接）
            old_state = self._extract_state(old_module)

            # 重新导入
            new_module = importlib.reload(old_module)

            # 恢复状态
            self._restore_state(new_module, old_state)

            # 更新引用
            self.loaded_modules[module_name] = new_module
            print(f"[热交换] {module_name} 已重载")
            return True
        return False

    def hot_reload_all(self):
        """热重载所有AivyOS模块"""
        target_modules = [
            "aivyos.modules.llm_engine",
            "aivyos.modules.memory",
            "aivyos.modules.tools",
            "aivyos.modules.scheduler",
            "aivyos.modules.persona",
        ]

        results = {}
        for mod in target_modules:
            results[mod] = self.hot_reload(mod)
        return results

    def _extract_state(self, module):
        """提取模块中需要保持的全局状态"""
        state = {}
        for attr in dir(module):
            if attr.startswith("_"):
                continue
            val = getattr(module, attr)
            # 保留连接对象、配置等不可重建的状态
            if isinstance(val, (Connection, dict, list)):
                state[attr] = val
        return state

    def _restore_state(self, module, state):
        """恢复全局状态到新模块"""
        for key, val in state.items():
            if not hasattr(module, key) or getattr(module, key) is None:
                setattr(module, key, val)
```

#### 3.1.2 模型热交换

```
class ModelHotSwapper:
    """LLM模型热交换器 — 加载新模型→切换→卸载旧模型"""

    def __init__(self):
        self.current_model = None
        self.current_name = None

    async def swap_model(self, model_name, model_path):
        """零停机模型切换"""
        # Step 1: 加载新模型到内存（旧模型仍在服务）
        new_model = await self._load_model(model_path)
        print(f"[热交换] 新模型 {model_name} 已加载")

        # Step 2: 原子切换引用
        old_model = self.current_model
        self.current_model = new_model
        self.current_name = model_name
        print(f"[热交换] 流量已切换到 {model_name}")

        # Step 3: 等待旧请求完成（graceful drain）
        await self._drain_pending(old_model)

        # Step 4: 卸载旧模型释放显存
        if old_model:
            del old_model
            torch.cuda.empty_cache()
            print(f"[热交换] 旧模型已卸载，显存已释放")

        return {"status": "swapped", "model": model_name}

    async def _load_model(self, path):
        """加载模型"""
        from vllm import LLM
        return LLM(model=path, dtype="float16",
                   gpu_memory_utilization=0.7)

    async def _drain_pending(self, model, timeout=30):
        """等待旧模型的所有推理请求完成"""
        start = time.time()
        while model.has_pending_requests():
            if time.time() - start > timeout:
                print("[热交换] 超时，强制切换（部分请求可能中断）")
                break
            await asyncio.sleep(0.1)
```

### 3.2 状态快照

    热交换前，系统对所有运行时状态做原子快照。如果热交换失败，从快照恢复。

      | 快照对象 | 内容 | 保存方式 | 恢复时间 |
| --- | --- | --- | --- |
| 会话上下文 | 当前对话历史、工作记忆 | JSON序列化 | class StateSnapshot:
    """状态快照管理器"""

    async def snapshot(self):
        """创建完整状态快照"""
        snap = {
            "timestamp": datetime.now().isoformat(),
            "version": CURRENT_VERSION,
            "session": await self._snapshot_session(),
            "tools": await self._snapshot_tools(),
            "scheduler": await self._snapshot_scheduler(),
            "browser": await self._snapshot_browser(),
        }

        # 原子写入
        path = Path("./.aivyos/snapshots/latest.json")
        path.parent.mkdir(parents=True, exist_ok=True)
        tmp = path.with_suffix(".tmp")
        tmp.write_text(json.dumps(snap, ensure_ascii=False))
        tmp.rename(path)

        return snap

    async def restore(self):
        """从快照恢复"""
        path = Path("./.aivyos/snapshots/latest.json")
        if not path.exists():
            return None

        snap = json.loads(path.read_text())

        # 按依赖顺序恢复
        await self._restore_session(snap["session"])
        await self._restore_scheduler(snap["scheduler"])
        await self._restore_tools(snap["tools"])
        await self._restore_browser(snap["browser"])

        return snap

### 3.3 验证与回滚

    热交换完成后，系统自动执行健康检查。全部通过才确认更新成功；任一失败则自动回滚。

      | 检查项 | 方法 | 超时 | 失败动作 |
| --- | --- | --- | --- |
| LLM推理 | 发送测试prompt，检查响应 | 10s | 回滚模型 |
| 记忆检索 | 执行测试查询，检查结果 | 5s | 回滚记忆模块 |
| 工具调用 | 调用web_search测试 | 10s | 回滚工具模块 |
| ASR/TTS | 发送测试音频，检查识别 | 5s | 回滚语音模块 |
| 调度器 | 检查定时任务是否正常 | 3s | 回滚调度器 |
| 前端渲染 | 检查WebView是否正常加载 | 5s | 回滚前端资源 |

            ("llm", self._check_llm),

            ("tools", self._check_tools),
            ("voice", self._check_voice),

                return {"healthy": False, "failed": name, "results": results}
