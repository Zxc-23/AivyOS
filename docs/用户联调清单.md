# AivyOS 用户联调清单（需在真实机器上完成的事项）

> 适用范围：沙箱开发环境无法覆盖的真实环境验证、可选重依赖安装、凭据安全事项。
> 原则：**全部功能已按"代码优先 + 优雅降级"实现** —— 下列事项不完成也能跑通核心链路，

## 一、必须验证（核心体验）

### 1.1 Tauri 桌面端真实运行

沙箱已验证至 `cargo check` / `tsc --noEmit` 通过，但无法启动 GUI / WebView2。
请在真实机器执行：

```powershell
cd shell
npm install          # 首次安装前端依赖
npm run tauri dev    # 开发模式运行（需 Rust 工具链 + WebView2）
```

验证点（对应实现位置）：
- [ ] 主窗口对话界面加载（React）
- [ ] **系统托盘 8 状态图标**：待命蓝/监听/工作绿/语音/更新/启动/异常红/暂停（`shell/src-tauri/src/tray.rs`）
- [ ] **全局热键**：Alt+Space 唤醒输入框 / Alt+V 语音 / Alt+S 截屏 / Alt+Q 退出（`shell/src/tray.ts`）
- [ ] **关闭窗口 → 最小化到托盘**（后台常驻，`App.tsx` onCloseRequested）
- [ ] **右键托盘菜单**：打开主界面/语音对话/截屏/暂停恢复/记忆管理/更新/设置/诊断/退出（§3.3）
- [ ] **双击托盘**（300ms 判定）→ 进入语音模式（§3.4）
- [ ] **开机自启**：首次启动自动 enable（§1.5）

> 如需打包安装包：`npm run tauri build`（需在 `tauri.conf.json` 配置 bundle 图标与签名）。

### 1.2 真实语音链路

`sounddevice` 已安装 ✅，但真实麦克风采集 + 播放需本机确认：

```powershell
python -m aivyos_core.voice --once "你好" --wav out.wav   # 单轮语音对话（采集→VAD→ASR→LLM→TTS→播放）
python -m aivyos_core.voice                                 # 交互式语音对话
```

- [ ] 麦克风采集正常（能量 VAD 已就绪，Silero 更准见 2.1）
- [ ] 播放正常
- [ ] 唤醒词（Aivy/艾维/贾维斯）触发（`voice.wake_required=True` 时生效）

### 1.3 ⚠️ GitHub Token 轮换（安全）

开发过程中 GitHub token 曾在对话中完整出现过。**建议立即轮换**：

```powershell
gh auth login        # 重新登录获取新 token
```

轮换后本仓库的自动推送（`scripts\gh_push.ps1` 经 `gh auth token`）会自动使用新凭据。

## 二、可选重依赖安装（按需启用真实能力）

> 未安装时全部优雅降级为 mock/占位，核心链路不受影响。
> ⚠️ 多数依赖需要 `torch`/`numpy`（体积大，建议逐个安装，不必一次全装）。

### 2.1 语音真实化（ASR / VAD / TTS）

```powershell
pip install funasr silero-vad     # ASR（SenseVoice）+ VAD（Silero v5，§3.1）
pip install cosyvoice             # TTS 音色克隆（§6.1，体积大）
```

验证：
- [ ] `python -m aivyos_core.asr` 识别真实语音
- [ ] TTS 合成真实人声（可配置 3 秒音色克隆 `tts.clone_ref_path`）
- [ ] `tests.test_voice` 真机链路（语音认证→ASR→LLM→TTS）

### 2.2 认证真实化（声纹 / 面部）

```powershell
pip install speechbrain           # 声纹 ECAPA-TDNN 192 维（§9.2）
pip install insightface           # 面部识别 Buffalo_L 512 维（§9.2）
```

验证：
- [ ] `python -m aivyos_core.auth register 张三 --wav voice.wav`（3-10 秒真实样本）
- [ ] `python -m aivyos_core.auth verify --wav test.wav`（本人通过 / 陌生人静默拒绝）

### 2.3 记忆真实化（Mem0）

```powershell
pip install mem0 chromadb         # Mem0 记忆后端（§4.2，BGE-M3 嵌入）
```

验证：`tests.test_mem0_contract`（add/search/update 契约对齐）

### 2.4 视觉真实化（OCR / 视觉理解）

```powershell
pip install paddleocr             # OCR（§3.3）
# 视觉理解需 Ollama 部署 qwen2-vl 模型：
ollama pull qwen2-vl:7b
```

验证：`python -m aivyos_core.vision` 截图/图片分析

### 2.5 浏览器自动化真实化（Vibe Coding 预览验证）

```powershell
pip install playwright browser-use
playwright install chromium
```

验证：
- [ ] `browser_navigate` / `browser_screenshot` 真实截图
- [ ] `browser_monitor` 控制台/网络事件真实捕获（§11）
- [ ] `browser_viewport` 多设备视口截图（T5.9）
- [ ] Vibe Coding 预览验证回环：console 错误 → 自动回 generate 修复（§10.1 阶段6 扩展）

### 2.6 python-api 模板运行

```powershell
pip install fastapi uvicorn
```

验证：`python scripts\smoke_codegen.py` 生成 python-api 项目后 `uvicorn main:app --reload`

## 三、已就绪 / 可选增强

| 事项 | 状态 | 启用方式 |
|---|---|---|
| Ollama + qwen2.5:3b / 0.5b | ✅ 已装可用 | 默认本地模型即 `qwen2.5:3b` |
| Node v24 + npm | ✅ 已装 | Cline 后端可用（见下） |

1. **先做第一节**：Tauri 跑起来（1.1）+ 语音试一轮（1.2）+ token 轮换（1.3）
