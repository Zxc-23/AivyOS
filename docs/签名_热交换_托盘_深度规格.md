## 一、更新签名机制 安全

    AivyOS 的自动更新涉及从远程服务器下载可执行代码并执行。签名机制是唯一保障——确保用户收到的更新包未被篡改且来源可信，同时防止攻击者通过降级攻击植入旧版漏洞。

### 1.1 密钥层级架构

    AivyOS 采用三层 PKI 密钥体系，遵循"根密钥永不触网"原则。每层密钥职责不同，泄露任一非根密钥不会导致整个体系崩溃。

      | 层级 | 密钥名称 | 算法 | 用途 | 存储位置 | 泄露影响 |
| --- | --- | --- | --- | --- | --- |
| L0 (Root) | Root CA | Ed25519 | 签发 Intermediate 证书 | 离线 HSM / 气隙机器 | 灾难级 — 全体系重建 |
| L1 (Intermediate) | Release Signing CA | Ed25519 | 签发 Code Signing 证书 | CI/CD 签名服务器 (TPM) | 严重 — 需撤销所有叶子证书 |
| L2 (Leaf) | Code Signing Key | Ed25519 | 签名实际更新包 | CI/CD 临时密钥 (每次发布) | 可控 — 撤销单次发布 |

      设计原则 — Root CA 私钥存储在气隙机器中，仅在签发新 Intermediate 证书时使用。Intermediate 证书有效期 1 年，Leaf 密钥仅用于单次发布（发布后立即销毁私钥）。客户端预置 Root CA 公钥作为信任锚点。

### 1.2 签名算法选型

      | 候选算法 | 密钥长度 | 签名长度 | 验证速度 | 是否后量子 | 选型决策 |
| --- | --- | --- | --- | --- | --- |
| **Ed25519** | 32 bytes | 64 bytes | ~50μs | 否 | **采用** — 签名快、长度小、无随机数陷阱 |
| RSA-2048 | 256 bytes | 256 bytes | ~100μs | 否 | 不采用 — 签名过大、性能差 |
| ECDSA P-256 | 32 bytes | 64 bytes | ~80μs | 否 | 不采用 — 需高质量随机数，有 k 值泄露风险 |
| Dilithium2 | 1312 bytes | 2420 bytes | ~200μs | 是 | 备用 — 待 NIST 标准成熟后迁移 |

    选择 Ed25519 的核心原因：

- 确定性签名 — Ed25519 签名不依赖随机数生成器质量，避免 ECDSA 的 k 值泄露灾难（如 Sony PS3 私钥泄露事件）。

- 小签名体积 — 64 字节签名 + 32 字节公钥，更新清单 (manifest) 增量极小。

- 快速验证 — 客户端验证耗时 ~50μs，在更新流程中可忽略不计。

- 抗侧信道 — Ed25519 运算不依赖秘密条件分支，天然抗 timing attack。

"""CI/CD 签名生成脚本 — 在隔离的签名服务器上执行"""
import hashlib
import json
import time
from pathlib import Path
from nacl.signing import SigningKey
from nacl.hash import blake2b

UPDATE_ROOT = Path("./build/update")
CHUNK_SIZE = 4 * 1024 * 1024  # 4 MB chunks

def build_manifest(version: str, update_type: str) -> dict:
    """构建更新清单：遍历所有文件，计算哈希"""
    manifest = {
        "version": version,
        "update_type": update_type,
        "timestamp": int(time.time()),
        "min_required_version": get_min_required(),
        "files": []
    }

    for file_path in sorted(UPDATE_ROOT.rglob("*")):
        if not file_path.is_file():
            continue

        # 计算文件级 BLAKE3 哈希
        file_hash = blake3_hash(file_path)
        # 计算分块哈希（大文件支持断点续传校验）
        chunks = chunk_hashes(file_path, CHUNK_SIZE)

        manifest["files"].append({
            "path": str(file_path.relative_to(UPDATE_ROOT)),
            "size": file_path.stat().st_size,
            "hash": file_hash,
            "chunks": chunks,
        })

    # 计算全包哈希（所有文件哈希的聚合）
    manifest["package_hash"] = aggregate_hash(manifest["files"])
    return manifest

def blake3_hash(path: Path) -> str:
    """计算文件 BLAKE3 哈希"""
    h = hashlib.blake2b(digest_size=32)
    with open(path, "rb") as f:
        while chunk := f.read(8192):
            h.update(chunk)
    return h.hexdigest()

def chunk_hashes(path: Path, chunk_size: int) -> list:
    """分块哈希 — 支持断点续传时逐块校验"""
    hashes = []
    with open(path, "rb") as f:
        while chunk := f.read(chunk_size):
            h = hashlib.blake2b(digest_size=32)
            h.update(chunk)
            hashes.append(h.hexdigest())
    return hashes

def sign_manifest(manifest: dict, leaf_key_path: str, cert_chain: list) -> dict:
    """用 Ed25519 Leaf 私钥签名清单"""
    # 序列化清单（确定性排序）
    manifest_bytes = json.dumps(manifest, sort_keys=True).encode()

    # 加载 Leaf 私钥（CI 环境变量注入，签名后清除）
    import os
    key_hex = os.environ["AIVY_LEAF_SIGNING_KEY"]
    signing_key = SigningKey(bytes.fromhex(key_hex))

    # Ed25519 签名
    signature = signing_key.sign(manifest_bytes).signature

    # 构建已签名清单
    signed_manifest = {
        "manifest": manifest,
        "signature": signature.hex(),
        "signer_pubkey": signing_key.verify_key.encode().hex(),
        "cert_chain": cert_chain,  # [Leaf证书, Intermediate证书]
    }
    return signed_manifest

### 1.4 客户端验签流程

    客户端下载更新包后，必须完整通过以下七步验证才能执行安装。任何一步失败，立即中止并上报。

      | 步骤 | 验证内容 | 失败动作 | 耗时 |
| --- | --- | --- | --- |
| ① 证书链验证 | Leaf → Intermediate → Root CA 信任链 | 拒绝更新，上报可疑活动 | ~1ms |
| ② 证书有效期 | 检查 not_before / not_after | 拒绝更新 |  当前版本号 | 拒绝更新，上报可疑活动 | """客户端验签器 — 下载后、安装前执行"""
import json
import hashlib
from pathlib import Path
from nacl.signing import VerifyKey
from naco.exceptions import BadSignatureError

# 预置信任锚点 — Root CA 公钥（编译时硬编码）
ROOT_CA_PUBKEY = bytes.fromhex("a1b2c3d4...")

class UpdateVerifier:
    """更新包验证器"""

    def __init__(self, current_version: str, crl_path: str = None):
        self.current_version = current_version
        self.crl = self._load_crl(crl_path)  # 证书撤销列表

    async def verify(self, signed_manifest: dict, package_dir: Path) -> bool:
        """完整七步验证，任一失败即返回 False"""

        # Step 1: 证书链验证
        cert_chain = signed_manifest["cert_chain"]
        if not self._verify_cert_chain(cert_chain):
            self._report("CERT_CHAIN_FAILED", "证书链验证失败")
            return False

        # Step 2: 证书有效期
        leaf_cert = cert_chain[0]
        if not self._check_cert_validity(leaf_cert):
            self._report("CERT_EXPIRED", "签名证书已过期")
            return False

        # Step 3: 撤销列表检查
        cert_id = leaf_cert["fingerprint"]
        if cert_id in self.crl:
            self._report("CERT_REVOKED", "签名证书已被撤销")
            return False

        # Step 4: Ed25519 签名验证
        manifest = signed_manifest["manifest"]
        signature = bytes.fromhex(signed_manifest["signature"])
        signer_pubkey = bytes.fromhex(signed_manifest["signer_pubkey"])

        manifest_bytes = json.dumps(manifest, sort_keys=True).encode()
        verify_key = VerifyKey(signer_pubkey)

        try:
            verify_key.verify(manifest_bytes, signature)
        except BadSignatureError:
            self._report("SIGNATURE_INVALID", "签名验证失败 — 包可能被篡改")
            self._quarantine(package_dir)
            return False

        # Step 5: 全包哈希校验
        package_hash = self._compute_package_hash(package_dir)
        if package_hash != manifest["package_hash"]:
            self._report("PACKAGE_HASH_MISMATCH", f"全包哈希不匹配: 期望 {manifest['package_hash'][:16]}... 实际 {package_hash[:16]}...")
            return False  # 触发重新下载

        # Step 6: 逐文件哈希校验
        for file_entry in manifest["files"]:
            file_path = package_dir / file_entry["path"]
            if not file_path.exists():
                self._report("FILE_MISSING", f"文件缺失: {file_entry['path']}")
                return False

            file_hash = self._blake3(file_path)
            if file_hash != file_entry["hash"]:
                self._report("FILE_HASH_MISMATCH", f"文件哈希不匹配: {file_entry['path']}")
                self._redownload_file(file_entry)
                return False

        # Step 7: 防降级检查
        new_version = manifest["version"]
        if not self._is_version_higher(new_version, self.current_version):
            self._report("DOWNGRADE_BLOCKED", f"拒绝降级: 当前 {self.current_version} >= 更新 {new_version}")
            return False

        print(f"[验签] 通过 — v{new_version} 可安全安装")
        return True

    def _verify_cert_chain(self, chain: list) -> bool:
        """验证 Leaf → Intermediate → Root 证书链"""
        # 验证 Leaf 被 Intermediate 签名
        if not verify_cert(chain[0], chain[1]):
            return False
        # 验证 Intermediate 被 Root 签名
        if not verify_cert(chain[1], {"pubkey": ROOT_CA_PUBKEY}):
            return False
        return True

    def _quarantine(self, package_dir: Path):
        """隔离可疑更新包"""
        quarantine_dir = Path("./.aivyos/quarantine")
        quarantine_dir.mkdir(exist_ok=True)
        import shutil
        shutil.move(str(package_dir), str(quarantine_dir / package_dir.name))

    def _report(self, code: str, message: str):
        """上报安全事件"""
        print(f"[安全警报] {code}: {message}")
        # 写入安全日志
        self._write_security_log(code, message)
        # 如果是篡改类事件，发送安全告警
        if code in ("SIGNATURE_INVALID", "CERT_REVOKED", "DOWNGRADE_BLOCKED"):
            self._send_security_alert(code, message)

    def _blake3(self, path: Path) -> str:
        """计算文件 BLAKE3 哈希"""
        h = hashlib.blake2b(digest_size=32)
        with open(path, "rb") as f:
            while chunk := f.read(8192):
                h.update(chunk)
        return h.hexdigest()
```

### 1.6 防篡改与防降级

#### 1.6.1 防篡改：哈希 + 签名双重保障

    攻击者即使能劫持 CDN 或中间人代理，也无法伪造更新包：

      | 攻击场景 | 防御机制 | 攻击结果 |
| --- | --- | --- |
| CDN 被入侵，替换二进制 | 逐文件 BLAKE3 哈希校验 | Step 6 拦截，文件被删除重下 |
| 中间人篡改 manifest | Ed25519 签名验证 | Step 4 拦截，包被隔离 |
| 中间人重放旧版 manifest | 时间戳 + 版本号检查 | Step 7 拦截，拒绝降级 |
| 自签名伪造证书 | Root CA 信任锚点预置 | Step 1 拦截，证书链断裂 |
| 混合攻击：真签名+假文件 | 签名覆盖 manifest（含文件哈希） | Step 4 签名验证失败（哈希不匹配 → manifest 篡改 → 签名失效） |

#### 1.6.2 防降级：版本单调递增 + 时间戳

    降级攻击（Downgrade Attack）指攻击者迫使客户端安装旧版本，利用旧版已知漏洞。AivyOS 通过三重防线防御：

- 语义版本号检查 — 客户端比较
```
new_version &gt; current_version
```
，拒绝任何降级。

- 时间戳新鲜度 — manifest 中的
```
timestamp
```
 必须在客户端当前时间 ±24 小时窗口内，拒绝过期或未来时间戳的 manifest。

- 降级白名单 — 仅
```
rollback_whitelist
```
 中列出的版本允许回滚（用于紧急回退场景），且白名单本身也被签名保护。

```
def _is_version_higher(self, new_ver: str, current_ver: str) -> bool:
    """语义版本比较 — 拒绝降级"""
    def parse(v):
        return tuple(int(x) for x in v.split("."))

    return parse(new_ver) > parse(current_ver)

def _check_timestamp_freshness(self, timestamp: int) -> bool:
    """时间戳新鲜度检查 — 防止重放"""
    now = int(time.time())
    max_drift = 24 * 3600  # 24 小时容差
    return abs(now - timestamp) &lt; max_drift

def _check_rollback_allowed(self, target_ver: str, whitelist: list) -> bool:
    """检查降级目标是否在白名单中"""
    return target_ver in whitelist
```

### 1.7 密钥轮换策略

      | 密钥层级 | 轮换周期 | 轮换触发条件 | 轮换流程 |
| --- | --- | --- | --- |
| Root CA | 10 年 | 定期 / 疑似泄露 | 气隙机器生成新密钥 → 签发新 Intermediate → 客户端下次更新时收到新 Root 公钥 |

    Root CA 公钥更新（信任锚点迁移）是最敏感的操作。客户端内置一个 Root CA 迁移表，在验证证书链时按序尝试新旧公钥，实现平滑过渡：

```

ROOT_CA_TRUST_ANCHORS = [
    {"pubkey": "a1b2c3d4...", "valid_from": "2026-01-01", "valid_until": "2035-12-31"},
    {"pubkey": "e5f6a7b8...", "valid_from": "2035-06-01", "valid_until": "2045-12-31"},  # 预置未来 Root
]

def verify_cert_chain(chain: list) -> bool:
    """验证时依次尝试所有 Root CA 锚点"""
    intermediate = chain[1]
    for anchor in ROOT_CA_TRUST_ANUSTORS:
        if is_within_validity(anchor, intermediate):
            if verify_signature(intermediate, anchor["pubkey"]):
                return True
    return False
```

## 二、热交换冲突处理 核心

    热交换（Hot Swap）在不停止进程的前提下替换模块代码。但"替换时模块正在被调用"会产生各种冲突。本章定义完整的冲突检测、隔离和解决体系，确保热交换期间零请求丢失、零状态损坏、零数据竞争。

### 2.2 读写锁与引用计数

    解决 C1（执行中热交换）和 C3（并发请求竞争）的核心机制：模块级读写锁。正常请求持读锁（可并发），热交换持写锁（独占）。热交换必须等所有读锁释放后才能执行。

```
import threading
import importlib
import sys
from contextlib import contextmanager
from typing import Any

class ModuleRWLock:
    """模块级读写锁 — 读操作可并发，写操作（热交换）独占"""

    def __init__(self):
        self._read_ready = threading.Condition(threading.Lock())
        self._readers = 0
        self._writer_active = False
        self._active_calls = 0  # 引用计数：当前活跃的模块调用数

    def acquire_read(self):
        """请求进入模块（读锁）"""
        with self._read_ready:
            while self._writer_active:
                self._read_ready.wait()  # 热交换进行中，等待
            self._readers += 1
            self._active_calls += 1

    def release_read(self):
        """离开模块"""
        with self._read_ready:
            self._readers -= 1
            self._active_calls -= 1
            if self._readers == 0:
                self._read_ready.notify_all()  # 通知等待的写者

    def acquire_write(self, timeout: float = 30.0):
        """获取写锁（热交换专用）— 等待所有读者离开"""
        deadline = time.time() + timeout
        with self._read_ready:
            while self._readers > 0:
                remaining = deadline - time.time()
                if remaining &lt;= 0:
                    raise TimeoutError(f"热交换超时：仍有 {self._readers} 个请求在执行")
                self._read_ready.wait(remaining)
            self._writer_active = True

    def release_write(self):
        """释放写锁"""
        with self._read_ready:
            self._writer_active = False
            self._read_ready.notify_all()  # 通知排队的读者

    @property
    def active_count(self):
        return self._active_calls

class SafeModuleProxy:
    """安全模块代理 — 所有模块调用经过读写锁保护"""

    def __init__(self, module_name: str):
        self.module_name = module_name
        self._lock = ModuleRWLock()
        self._module = importlib.import_module(module_name)

    def call(self, method_name: str, *args, **kwargs) -> Any:
        """安全调用模块方法（持读锁）"""
        self._lock.acquire_read()
        try:
            method = getattr(self._module, method_name)
            return method(*args, **kwargs)
        finally:
            self._lock.release_read()

    async def acall(self, method_name: str, *args, **kwargs) -> Any:
        """异步安全调用"""
        self._lock.acquire_read()
        try:
            method = getattr(self._module, method_name)
            return await method(*args, **kwargs)
        finally:
            self._lock.release_read()

    def hot_swap(self, timeout: float = 30.0) -> bool:
        """热交换模块（持写锁）"""
        self._lock.acquire_write(timeout)
        try:
            old_module = self._module
            old_state = self._extract_persistent_state(old_module)

            # 重新加载
            new_module = importlib.reload(old_module)

            # 状态迁移
            self._migrate_state(new_module, old_state)

            # 原子切换指针
            self._module = new_module
            return True
        except Exception as e:
            print(f"[热交换] 失败: {e}")
            return False
        finally:
            self._lock.release_write()

    def _extract_persistent_state(self, module) -> dict:
        """提取需要跨版本保持的状态"""
        state = {}
        persistent_attrs = getattr(module, "_PERSISTENT_STATE__", [])
        for attr in persistent_attrs:
            if hasattr(module, attr):
                state[attr] = getattr(module, attr)
        return state

    def _migrate_state(self, new_module, old_state: dict):
        """状态迁移 — 如果新模块定义了迁移函数，调用它"""
        if hasattr(new_module, "_migrate_state_"):
            new_state = new_module._migrate_state_(old_state, from_version="auto")
            for key, val in new_state.items():
                setattr(new_module, key, val)
        else:
            # 无迁移函数 — 直接恢复
            for key, val in old_state.items():
                if hasattr(new_module, key):
                    setattr(new_module, key, val)

# === 使用示例 ===
llm_proxy = SafeModuleProxy("aivyos.modules.llm_engine")

# 正常请求（自动持读锁，可并发）
response = llm_proxy.call("generate", prompt="你好", max_tokens=100)

# 热交换（持写锁，等待所有请求完成）
success = llm_proxy.hot_swap(timeout=30)
```

### 2.3 Drain 策略与优雅切换

    热交换不是瞬间完成的——必须排空（Drain）旧模块上的所有活跃请求，才能安全替换。Drain 策略定义了完整的排空生命周期。

      | Drain 阶段 | 动作 | 超时 | 超时后动作 |
| --- | --- | --- | --- |
| D1: 进入排空 | 设置
```
draining=True
```
，拒绝新请求入队 | — | — |
| D2: 请求排队 | 新请求进入等待队列，不进入旧模块 | 30s | 超时后请求转入新模块 |
| D3: 等待活跃请求完成 | 轮询
```
active_count → 0
```
 | 30s | 强制切换 — 标记中断请求 |
| D4: 状态提取 | 从旧模块提取持久状态 | 5s | 跳过状态迁移，使用快照 |
| D5: 模块重载 |
```
importlib.reload()
```
 | 10s | 回滚到旧模块 |
| D6: 状态恢复 | 迁移并恢复状态到新模块 | 5s | 跳过，继续无状态启动 |
| D7: 健康检查 | 执行验证测试 | 10s | 回滚 |
| D8: 放行排队请求 | 队列中的请求转入新模块执行 | — | — |

```
class DrainManager:
    """Drain 排空管理器 — 协调热交换全流程"""

    PHASES = ["entering", "queueing", "draining", "extracting",
              "reloading", "restoring", "verifying", "releasing"]

    def __init__(self, proxy: SafeModuleProxy):
        self.proxy = proxy
        self.phase = "idle"
        self.request_queue = asyncio.Queue()
        self.draining = False

    async def execute_hot_swap(self) -> dict:
        """执行完整的 Drain 热交换流程"""
        results = {}

        # D1: 进入排空
        self.phase = "entering"
        self.draining = True
        results["entered"] = True

        # D2 + D3: 排空活跃请求（并发等待）
        self.phase = "draining"
        drain_result = await self._drain_active(timeout=30)
        results["drain"] = drain_result

        if not drain_result["success"]:
            # 超时 — 标记中断
            await self._mark_interrupted()
            results["forced"] = True

        # D4: 状态提取
        self.phase = "extracting"
        old_state = self.proxy._extract_persistent_state(self.proxy._module)

        # D5: 模块重载
        self.phase = "reloading"
        try:
            old_module = self.proxy._module
            new_module = importlib.reload(old_module)
        except Exception as e:
            results["reload_failed"] = str(e)
            self.draining = False
            return results

        # D6: 状态恢复
        self.phase = "restoring"
        self.proxy._migrate_state(new_module, old_state)
        self.proxy._module = new_module  # 原子指针切换

        # D7: 健康检查
        self.phase = "verifying"
        health = await self._health_check(timeout=10)
        if not health["healthy"]:
            # 回滚
            await self._rollback(old_module, old_state)
            self.draining = False
            results["rolled_back"] = True
            return results

        # D8: 放行排队请求
        self.phase = "releasing"
        self.draining = False
        await self._flush_queue()

        results["success"] = True
        return results

    async def _drain_active(self, timeout: float = 30) -> dict:
        """等待所有活跃请求完成"""
        start = time.time()
        while self.proxy._lock.active_count > 0:
            elapsed = time.time() - start
            if elapsed > timeout:
                return {
                    "success": False,
                    "remaining": self.proxy._lock.active_count,
                    "elapsed": elapsed
                }
            await asyncio.sleep(0.05)  # 50ms 轮询

        return {"success": True, "elapsed": time.time() - start}

    async def _flush_queue(self):
        """放行排队请求到新模块"""
        while not self.request_queue.empty():
            request = await self.request_queue.get()
            # 重新提交到新模块
            asyncio.create_task(self._execute_queued(request))

    async def _execute_queued(self, request):
        """执行排队的请求"""
        self.proxy._lock.acquire_read()
        try:
            method = getattr(self.proxy._module, request["method"])
            result = await method(*request["args"], **request["kwargs"])
            request["future"].set_result(result)
        except Exception as e:
            request["future"].set_exception(e)
        finally:
            self.proxy._lock.release_read()
```

### 2.4 状态迁移兼容

    解决 C2（状态结构不兼容）。新旧模块版本可能使用不同的状态 schema，直接恢复旧状态会导致属性缺失或类型不匹配。每个模块声明自己的 schema 版本和迁移函数。

```
# === aivyos/modules/llm_engine.py ===

# 模块状态 schema 版本声明
_STATE_SCHEMA_VERSION__ = 3
_PERSISTENT_STATE__ = ["model_config", "conversation_buffer", "token_count"]

# 从旧版状态迁移到当前版
def _migrate_state_(old_state: dict, from_version: str = "auto") -> dict:
    """状态迁移函数 — 处理跨版本 schema 差异"""

    # 自动检测旧版本
    old_ver = old_state.get("_state_schema_version__", 1)

    # v1 → v2: conversation_buffer 从 list 改为 dict
    if old_ver &lt; 2:
        buf = old_state.get("conversation_buffer", [])
        old_state["conversation_buffer"] = {
            "messages": buf,
            "metadata": {"truncated": False}
        }

    # v2 → v3: model_config 新增 max_context_length 字段
    if old_ver &lt; 3:
        config = old_state.get("model_config", {})
        config.setdefault("max_context_length", 4096)
        config.setdefault("temperature_default", 0.7)
        old_state["model_config"] = config

    # 标记为当前版本
    old_state["_state_schema_version__"] = _STATE_SCHEMA_VERSION__
    return old_state

# === 状态快照格式（版本化）===
"""
{
  "_state_schema_version__": 3,
  "model_config": {
    "model_name": "qwen2.5-7b",
    "dtype": "float16",
    "max_context_length": 4096,    // v3 新增
    "temperature_default": 0.7     // v3 新增
  },
  "conversation_buffer": {
    "messages": [...],             // v2: list → dict.messages
    "metadata": {"truncated": false}  // v2 新增
  },
  "token_count": 15234
}
"""

### 2.6 熔断与降级

    当热交换连续失败时，系统进入熔断状态，停止尝试热交换，降级为"下载后下次冷启动安装"模式。

```
class HotSwapCircuitBreaker:
    """热交换熔断器 — 连续失败后停止热交换尝试"""

    def __init__(self, failure_threshold: int = 3, cooldown: float = 3600):
        self.failure_threshold = failure_threshold
        self.cooldown = cooldown  # 熔断后冷却 1 小时
        self.failure_count = 0
        self.state = "closed"  # closed / open / half_open
        self.last_failure_time = None

    def can_attempt(self) -> bool:
        """是否允许尝试热交换"""
        if self.state == "closed":
            return True

        if self.state == "open":
            # 检查是否过了冷却期
            if time.time() - self.last_failure_time > self.cooldown:
                self.state = "half_open"
                return True
            return False

        if self.state == "half_open":
            return True  # 允许一次试探

    def record_success(self):
        """热交换成功"""
        self.failure_count = 0
        self.state = "closed"

    def record_failure(self):
        """热交换失败"""
        self.failure_count += 1
        self.last_failure_time = time.time()

        if self.failure_count >= self.failure_threshold:
            self.state = "open"
            print(f"[熔断] 热交换连续失败 {self.failure_count} 次，"
                  f"进入熔断状态，{self.cooldown}s 后重试")
            # 降级：通知更新器改用冷启动安装
            self._notify_degrade_to_cold_install()

    def _notify_degrade_to_cold_install(self):
        """通知更新器：热交换不可用，改用冷启动"""
        # 更新器将下载完整包，下次启动时安装
        pass

# === 集成到热交换流程 ===
breaker = HotSwapCircuitBreaker(failure_threshold=3, cooldown=3600)

async def safe_hot_swap(proxy: SafeModuleProxy) -> dict:
    """带熔断保护的热交换"""
    if not breaker.can_attempt():
        return {
            "success": False,
            "reason": "circuit_open",
            "message": "热交换熔断中，将改为下次启动安装"
        }

    drain = DrainManager(proxy)
    result = await drain.execute_hot_swap()

    if result.get("success"):
        breaker.record_success()
    else:
        breaker.record_failure()

    return result
```

      零中断保证 — 通过读写锁 + Drain 排空 + 熔断降级三层机制，AivyOS 保证：① 热交换期间无请求丢失（排队等待）；② 热交换失败时无状态损坏（回滚 + 快照恢复）；③ 连续失败时不反复尝试（熔断保护）。用户最差体验是 30s 延迟后通知"改为下次启动安装"。

import { TrayIcon } from "@tauri-apps/api/tray";
import { getCurrentWindow } from "@tauri-apps/api/window";

const win = getCurrentWindow();
let lastClickTime = 0;

tray.onClick(async ({ button }) => {
    if (button === "Left") {
        const now = Date.now();
        const isDoubleClick = (now - lastClickTime) &lt; 300;
        lastClickTime = now;

        if (isDoubleClick) {
            // 双击 — 进入语音模式（见 3.4）
            await enterVoiceMode();
            return;
        }

        // 单击 — 切换窗口可见性
        const visible = await win.isVisible();
        const state = getCurrentTrayState();

        if (state === "booting") {
            // 启动中，忽略
            return;
        }

        if (state === "error") {
            // 异常状态 — 显示错误面板
            await win.show();
            await win.setFocus();
            await navigateToSection("error-panel");
            return;
        }

        if (state === "updating") {
            // 更新中 — 显示进度
            await win.show();
            await win.setFocus();
            await navigateToSection("update-progress");
            return;
        }

        // 正常状态 — 切换可见性
        if (visible) {
            await win.hide();
            // 仅在非 working 状态显示气泡
            if (state === "idle") {
                await sendTrayToast("AivyOS", "我还在后台运行");
            }
        } else {
            await win.show();
            await win.setFocus();
            await win.requestUserAttention();

            // working 状态 — 滚动到任务进度
            if (state === "working") {
                await navigateToSection("task-progress");
            }
        }
    }
});

// 300ms 内无第二次点击 → 确认为单击
setTimeout(() => {
    if (Date.now() - lastClickTime >= 300) {
        // 单击已确认执行
    }

### 3.6 托盘气泡通知策略

    通知是 AI 主动触达用户的渠道。不同优先级消息有不同的展示策略和打扰程度。

      | 通知级别 | 触发场景 | 展示方式 | 勿扰模式 | 点击动作 |
| --- | --- | --- | --- | --- |
| **紧急** | 系统异常、安全告警、主人认证失败 | 系统级通知 + 托盘图标变红闪烁 | 绕过勿扰 | 打开异常处理面板 |
| **重要** | 定时任务完成、更新可用、文件分析完成 | 系统级通知 + 通知声 | 静默排队，恢复勿扰后显示 | 打开主窗口对应详情 |
| **普通** | AI 主动建议、信息摘要、提醒事项 | 系统级通知 | 静默排队 | 打开主窗口 |
| **静默** | 记忆整理完成、后台索引更新、优化完成 | 仅写入通知中心，不弹气泡 | 不显示 | 通知中心点击查看 |

class TrayNotificationManager:
    """托盘通知管理器 — 分级推送策略"""

    LEVELS = {
        "urgent":   {"bypass_dnd": True,  "sound": True,  "icon_flash": True,  "duration": 0},
        "important": {"bypass_dnd": False, "sound": True,  "icon_flash": False, "duration": 5000},
        "normal":   {"bypass_dnd": False, "sound": False, "icon_flash": False, "duration": 4000},
        "silent":   {"bypass_dnd": False, "sound": False, "icon_flash": False, "duration": 0},
    }

    async def send(self, title: str, body: str, level: str = "normal",
                   actions: list = None):
        """发送分级通知"""
        config = self.LEVELS[level]

        # 检查勿扰模式
        if not config["bypass_dnd"] and self._is_dnd_active():
            # 静默排队，恢复后显示
            await self._queue(title, body, level, actions)
            return

        # 设置托盘图标行为
        if config["icon_flash"]:
            await self._flash_icon("error")

        # 播放提示音
        if config["sound"]:
            await play_sound("notification.wav")

        # 发送系统通知
        await sendNotification({
            "title": title,
            "body": body,
            "iconPath": self._get_icon_for_level(level),
            "duration": config["duration"],
            "actions": actions or [],  # [{"id": "ok", "title": "确认"}, ...]
        })

    def _is_dnd_active(self) -> bool:
        """检查当前是否处于勿扰模式"""
        # Windows: 检查专注助手状态
        # macOS: 检查 NSUserNotification 勿扰设置
        return get_system_dnd_status()

    async def _queue(self, title, body, level, actions):
        """静默排队 — 勿扰恢复后批量显示"""
        self._pending_queue.append({
            "title": title, "body": body,
            "level": level, "actions": actions,
            "timestamp": time.time()
        })

    async def flush_pending(self):
        """勿扰恢复后 — 批量显示排队的通知"""
        while self._pending_queue:
            item = self._pending_queue.pop(0)
            # 合并最近 5 分钟的通知为一条摘要
            await self.send(item["title"], item["body"], "normal", item["actions"])

class TrayIconManager:
    """托盘图标动态管理"""

    ICON_SETS = {
        "idle":       {"icon": "tray-idle",       "tooltip": "AivyOS — 待命中"},
        "listening":  {"icon": "tray-listening",  "tooltip": "AivyOS — 监听中"},

        "updating":   {"icon": "tray-updating",   "tooltip": "AivyOS — 更新中"},
        "booting":    {"icon": "tray-booting",    "tooltip": "AivyOS — 正在恢复..."},
        "error":      {"icon": "tray-error",      "tooltip": "AivyOS — 异常"},
        "paused":     {"icon": "tray-paused",     "tooltip": "AivyOS — 已暂停"},
    }

    def __init__(self, tray: TrayIcon):
        self.tray = tray
        self.current_state = "idle"
        self.animation_timer = None

    def set_state(self, state: str, detail: str = None):
        """切换托盘状态"""
        config = self.ICON_SETS[state]
        icon_path = f"icons/{config['icon']}.png"
        tooltip = config["tooltip"]

        if detail:
            tooltip += f" {detail}"  # 如 ": 代码审查"

        self.tray.setIcon(icon_path)
        self.tray.setTooltip(tooltip)
        self.current_state = state

        # 启动/停止动画
        self._update_animation(state)

    def _update_animation(self, state: str):
        """管理图标动画"""
        # 停止上一个动画
        if self.animation_timer:
            self.animation_timer.cancel()

        if state == "listening":
            # 脉动呼吸：周期性改变图标透明度
            self._start_pulse()
        elif state == "working":
            # 旋转齿轮：切换帧
            self._start_rotation()
        elif state == "error":
            # 闪烁：交替显示/隐藏
            self._start_flash()
        elif state == "booting":
            # 快速闪烁
            self._start_flash(interval=0.5)
        elif state == "updating":
            # 进度环：根据下载进度切换帧
            pass  # 由 update_progress 回调驱动

    def _start_pulse(self):
        """脉动呼吸动画"""
        import itertools
        icons = ["tray-listening-0", "tray-listening-1",
                  "tray-listening-2", "tray-listening-1"]

        def cycle():
            for icon in itertools.cycle(icons):
                if self.current_state != "listening":
                    return
                self.tray.setIcon(f"icons/{icon}.png")
                time.sleep(0.5)  # 2s 周期

        threading.Thread(target=cycle, daemon=True).start()

    def set_update_progress(self, pct: float):
        """更新进度（updating 状态专用）"""
        if self.current_state != "updating":
            return
        # 10 帧进度环
        frame = int(pct * 10) // 10
        self.tray.setIcon(f"icons/tray-updating-{frame}.png")
        self.tray.setTooltip(f"AivyOS — 更新中 {int(pct*100)}%")
